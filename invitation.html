Partagez les menus de votre foyer

Une personne vous invite à retrouver les mêmes menus, courses et préparations dans Mijotéo.

Vous avez déjà Mijotéo

Ouvrez l’application et connectez-vous avec l’adresse e-mail qui a reçu l’invitation. Dans Profil, ouvrez Compte et partage puis acceptez l’invitation.

Vous découvrez Mijotéo

Installez l’application, puis créez votre compte avec cette même adresse e-mail. Confirmez votre adresse et retrouvez l’invitation dans Compte et partage.

Télécharger Mijotéo

Code de secours

Si l’invitation n’apparaît pas, collez ce code dans « J’ai reçu un code d’invitation ». Dans les anciennes versions, ouvrez Foyer puis « Rejoindre un foyer ».

L’invitation expire après sept jours. Accepter le partage conserve une copie de vos menus locaux. Aucune adhésion n’est effectuée en ouvrant cette page.
